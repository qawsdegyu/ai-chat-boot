# إجابات مباشرة من ملفات OneDrive

هذه النسخة لا تكتفي بإرسال السؤال إلى النموذج. تبحث أولًا في خلايا OneDrive المفهرسة، وتعيد القيمة المطابقة مع اسم الملف واسم الورقة وعنوان الخلية. إذا أعاد النموذج مخطط JSON بدل إجابة، يستخدم النظام نتائج الخلايا المباشرة ولا يعرض المخطط للمستخدم.

مثال اختبار: `PDUS1189` موجود في `IMCAN-Reference-Sheet---2024 (1).xlsm`، ورقة `Inventory`، الخلية `C3`.

شغّل `pnpm install` ثم جهّز `.env` من `.env.example` ثم شغّل `pnpm dev`.
